# Example of offline MLP model training and running inference on Micropython
## Sample problem: Sine wave Regression

A jupyter notebook (.ipynb file) is provided to train the model in your pc/Google colab and save the model as .bin File. Then upload the trained model (.bin file) into your board and run micropython [inference](https://github.com/charlie2951/microml/blob/main/examples/mlp_inference/inference_mlp_sine.py) and see prediction.
