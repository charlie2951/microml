# Demonstration of CNN Inferencing 
## Example: MNIST handwritten digit prediction
A sample [Jupyter notebook](https://github.com/charlie2951/microml/blob/main/examples/CNN_microml_mnist/train_cnn_mnist_micropython.ipynb) is provided to train the model locally (or in Google Colab) and save the trained model as .bin file. Then upload the model into your
board and run [inference script](https://github.com/charlie2951/microml/blob/main/examples/CNN_microml_mnist/inference_cnn_mnist.py) to predict digit. Sample csv file (digit0 to digit9 data) is provided for prediction.
